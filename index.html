Content-extractor

J'ai refait le service d'extraction de zéro : OCR, images, PDF, DOCX.
Batch async avec Celery + API batch Mistral. Résultat : -50% sur les coûts d'extraction.
Patterns factory/registry, donc on ajoute un nouveau format sans toucher au reste.

RAG · ~100k documents

PDFs, notices techniques, work orders, KPIs. Tout est indexé.
Plusieurs agents RAG selon le type de question, orchestrés via MCP. Le routage LLM choisit le bon agent automatiquement.
Chaque réponse cite ses sources dans le texte, traçable jusqu'au document d'origine.

MCP Builder

On donne une spec OpenAPI, l'outil génère un serveur MCP.
Un agent regroupe les endpoints par domaine, génère la doc et filtre les routes inutiles.
120+ APIs internes déjà connectées. C'est ce qui fait la transition SaaS → AaaS.

Pipelines Airflow

5 DAGs d'ingestion, un par client. Segmentation, chunking et indexation à grande échelle.

Infra

Dockerfile, docker-compose, configuration Celery. Un seul DevOps dans l'équipe, forte autonomie sur l'infra.
